# DotWar

Vite + React + TypeScript starter for a portrait-first mobile game. The sample
game is a 30-second tap-the-target challenge.

## Run locally

```bash
npm install
npm run dev
```

Use your browser's mobile device emulation to preview the portrait layout.

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository in Vercel and deploy with the Vite defaults:

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`

The included `vercel.json` sends app routes to the SPA entry point.
